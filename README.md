# Krishna Kumar T S, portfolio

Static site: one HTML page and one stylesheet. No JavaScript, no build step.

```
index.html          redirect to portfolio.html
portfolio.html      the portfolio
css/style.css       all styling (Archivo from Google Fonts)
assets/             photo, resume PDF, favicon, social preview image
```

Run locally: `python -m http.server 5173`, then open http://localhost:5173/portfolio.html

Live: https://krishnakumar-ts.github.io/krishnakumar-ts-cloud-gtm/portfolio.html

Content rule: no employer content, artwork, brand assets, client names or internal metrics on this site (NDA clause 8). Describe the work in words only.
