# Krishna Kumar T S, portfolio

Static hiring portfolio: one HTML page, one stylesheet, one small script. No build step, no framework.

```
index.html          redirect to portfolio.html
portfolio.html      the portfolio
css/style.css       all styling (Newsreader, Geist, Geist Mono from Google Fonts)
js/site.js          nav highlight, image lightbox, copy-email, review mode
assets/             résumé PDF, portrait, explainer images, video, favicon, social preview
```

Run locally: `python -m http.server 5199`, then open http://localhost:5199/portfolio.html

Review mode: add `?review` to the URL to show yellow notes where evidence is still missing.

Live: https://krishnakumar-ts.github.io/krishnakumar-ts-cloud-gtm/portfolio.html

Content rules: no client names, internal files or revenue figures (employment agreement). No city name; location is "Tamil Nadu, India". Every claim must trace to job-search-2026/00-career-analysis/Verified-Candidate-Profile.md.
